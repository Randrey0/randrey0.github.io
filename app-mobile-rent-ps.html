App Mobile Rent Playstation

Mobile PlayStation Rental Application is a mobile application designed to manage PlayStation console inventory and member data in a structured manner. The application is integrated with a MockAPI-based database and implements full CRUD (Create, Read, Update, Delete) functionality for both console and member data. Developed using Flutter (Dart), this application provides efficient data management with a responsive user interface. This project was developed as part of the Mobile Programming course requirements.
