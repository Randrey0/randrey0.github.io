PlayStation (PS) Rental Website Management System

The PlayStation (PS) Rental Website is a web-based application developed to facilitate online PlayStation rentals without requiring customers to visit the rental location. Through this system, users can register, log in, select available PlayStation consoles, and place rental orders anytime and from anywhere. The rented PlayStation units are delivered directly to the customer’s registered address.

This website consists of two main components: a Front-End for users and a Back-End for administrators. On the user side, the system provides authentication features (registration and login), console selection, and rental transactions. On the admin side, the system supports CRUD (Create, Read, Update, Delete) operations for managing console categories and inventory, monitoring stock availability, and generating rental reports.

The application was developed using the CodeIgniter 3 PHP framework and MySQL database, implementing the MVC (Model-View-Controller) architecture to ensure a well-structured and maintainable system. This project demonstrates practical skills in web application development, database management, and the implementation of an integrated rental management system for both users and administrators.
